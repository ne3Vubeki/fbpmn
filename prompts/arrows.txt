Разработай функционал создания новой связи между узлами/атрибутами.
Следующий сценарий. 
В lib\src\widgets\resize_handles.dart в методах _buildSideHandle и _buildAllAttributesHighlightChildren при клике по кружку нужно создавать новую связь.
В зависимости от метода создается связь между узлами, между атрибутами или узлом и атрибутом. Нужно предусмотреть следующий сценарий создания связи:
Этап 1:
Выделяем нужный начальный узел. Выбираем нужный кружок создания связи.
Клик по кружку открывает меню виджета MenuAnchor (нужно создать) и в нем выбирается нужный тип связи. 
Названия типов: Стрелка, Ромб, Ромб пустой, Линия. Для этих типов связи создаются по шаблону соответственно:
1. targetArrow = 'block', powers - нет
2. sourceArrow = 'diamondThin', powers=[
        {
          "qType": "arrowPower",
          "id": "",
          "value": "n",
          "side": "1"
        },
        {
          "qType": "arrowPower",
          "id": "",
          "value": "1",
          "side": "-1"
        }
      ]
3. sourceArrow = 'diamond', powers=[
        {
          "qType": "arrowPower",
          "id": "",
          "value": "n",
          "side": "1"
        },
        {
          "qType": "arrowPower",
          "id": "",
          "value": "1",
          "side": "-1"
        }
      ]
4. powers=[
        {
          "qType": "arrowPower",
          "id": "",
          "value": "1",
          "side": "1"
        },
        {
          "qType": "arrowPower",
          "id": "",
          "value": "1",
          "side": "-1"
        }
      ]
Модель для создания связи: lib\src\models\arrow.dart, lib\src\models\power.dart.
Для заполнения id нужно использовать менеджер id в lib\src\services\id_manager.dart.
После выбора типа связи, меню закрывается и создается новая связь, добавляясь в arrowCreated в lib\src\editor_state.dart, 
где свойство source привязано к id узла или атрибута, в котором стартовало создание связи. 
Для отображения вновь создаваемых связей нужно создать новый виджет arrow_created.dart.
Новая связь начинает отображаться над выделеным узлом и имеет красный цвет.
Виджет отображается, если arrowCreated не пустой.
Этап 2:
Ведем мышкой target конец связи выбирая другой узл или другой атрибута текущего узла. 
При ховере на другой узел он переносится в state.nodesSelected без перерисовки в тайлах, отображается как выделенный, но без рисования кружков _buildSideHandle и _buildResizeButton.
Нужно использовать для ховера узла виджет lib\src\widgets\node_hover.dart, перенеся 
Узел при ховера конца новой связи находится методом findNodeAtWorldPosition в lib\src\services\node_manager.dart.
Внутри такого узла по клику на кружок создания связи создается новая связь с выбранным ранее типом и с таргетом на узле или атрибуте. 
Этап 3:
Узел, который был выделен ховером после создания связи удаляется из state.nodesSelected и перестает быть выделеным.
Новая связь переносится из arrowCreated в arrowsSelected.
Тайлы на этом этапе не перерисовываются. Перерисовывается выделенный начальный узел и его связи.
Дополнительно:
- Если кликнуть на пустую область экрана, то создание связи прерывается и она удаляется. 
- Также нужно добавить отмену создания связи по кнопке Esc
- Связь на этапе 2 должна отображаться на экране используя метод calculateConnectionPoints в lib\src\services\arrow_manager.dart.
